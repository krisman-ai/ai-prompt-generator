# AI Prompt Generator (Portfolio Tool)

Web app Streamlit untuk membuat prompt berkualitas (marketer/designer/ChatGPT user) menggunakan OpenAI API.

## Features
- Generate Base Prompt (template)
- Refine with AI (OpenAI API)
- Download hasil prompt (TXT/MD)

## Run locally
```bash
pip install -r requirements.txt
python -m streamlit run app.py
